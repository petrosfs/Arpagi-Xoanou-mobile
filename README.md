# Η Αρπαγή του Ξόανου (The Theft of the Xoanon)

Παιχνίδι ταχύτητας για κινητά, για 2–10 παίκτες. Οι παίκτες γυρίζουν κάρτες με τη σειρά, και όταν
δύο κάρτες έχουν το ίδιο σύμβολο, κερδίζει όποιος αρπάξει πρώτος το ξόανο.

- **Solo** απέναντι σε 1–9 bots, σε 4 επίπεδα δυσκολίας (παίζει και χωρίς internet).
- **Online με φίλους**, ο καθένας από το κινητό του, με κωδικό δωματίου ή σύνδεσμο πρόσκλησης.
- **Ελληνικά και αγγλικά** (αυτόματα από τη γλώσσα του κινητού), σελίδα κανόνων, ρύθμιση για δυσχρωματοψία.

## Πώς είναι φτιαγμένο

- **TypeScript + Vite**, χωρίς UI framework, για ελάχιστη καθυστέρηση στην απόκριση.
- **3D με CSS** (γύρισμα καρτών, τραπέζι με βάθος, κάρτες που πετούν), μόνο με transform/opacity ώστε να
  μην επιβαρύνεται η ταχύτητα. Οι κάρτες μένουν πάντα επίπεδες για άμεση αναγνώριση.
- **Μηχανή κανόνων** σε καθαρό, ντετερμινιστικό TypeScript (`src/engine`), με τεστ και προσομοιώσεις.
- **Δίκαιο άρπαγμα:** κάθε κινητό μετράει τοπικά τον χρόνο αντίδρασης από τη στιγμή που εμφανίστηκε η
  κάρτα, ώστε η καθυστέρηση του δικτύου να μην αδικεί κανέναν. Σε ισοπαλία μετράνε τα δάχτυλα και
  πόσο κοντά στη βάση πιάστηκε το ξόανο.
- **Online:** ένα κινητό είναι ο host και τρέχει τη μηχανή. Οι υπόλοιποι συνδέονται απευθείας μαζί του
  με **WebRTC**. Το **Firebase Realtime Database** χρησιμοποιείται για δωμάτια, σύνδεση και παρουσία,
  και ως εναλλακτική αναμετάδοση όταν το WebRTC δεν ανοίγει. Αν φύγει ο host, αναλαμβάνει αυτόματα
  άλλος παίκτης και η παρτίδα συνεχίζει.
- **Φιλοξενία:** GitHub Pages, με αυτόματο test, build και deploy μέσω GitHub Actions. Μηδενικό κόστος.

## Τοπική εκτέλεση

```bash
npm install
npm run dev     # τοπικός server
npm test        # τεστ
npm run build   # build στον φάκελο dist
```

Οι κανόνες ασφαλείας της βάσης βρίσκονται στο `database.rules.json`.
