# Η Αρπαγή του Ξόανου (The Theft of the Xoanon)

Online παιχνίδι ταχύτητας για κινητά, για 2–10 παίκτες, με solo παιχνίδι απέναντι σε bots.

## Τοπική εκτέλεση

```bash
npm install
npm run dev     # τοπικός server
npm test        # τεστ
npm run build   # build στον φάκελο dist
```

## Deploy

Κάθε push στο `main` κάνει αυτόματα test, build και deploy στο GitHub Pages μέσω GitHub Actions.
